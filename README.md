# tutor-finder-docs

Документация web-приложения для онлайн-подбора репетиторов

TutorFinder — web-приложение для онлайн-подбора репетиторов, ориентированное на школьников и студентов. Ученики могут находить репетиторов по предметам и отправлять им заявки. Репетиторы управляют входящими заявками и принимают или отклоняют их.

Приложение реализуется с использованием клиент-серверной архитектуры:

- Клиентская часть — web-приложение на HTML + JavaScript.
- Серверная часть — REST API, написанное на Python с использованием FastAPI.

Репозиторий приложения: [tutor-finder](https://github.com/Chirkov-Arhip/tutor-finder)

## Функции приложения

- Регистрация и вход в аккаунт
- Два типа пользователей — ученик и репетитор
- Заполнение профиля с личными данными
- Поиск репетиторов с фильтрацией по предметам
- Отправка заявки репетитору с указанием предмета
- Принятие и отклонение заявок репетитором
- Обмен контактами после принятия заявки
- Редактирование профиля с подтверждением паролем
- Обращение в техподдержку с отправкой письма на почту

## Диаграммы C4

Диаграммы C4 — это набор диаграмм для визуализации архитектуры программного обеспечения на разных уровнях детализации.

### Диаграмма контекста

[context.md](c4/context.md) — показывает систему в масштабе её взаимодействия с пользователями. Описывает кто использует систему и как.

### Диаграмма контейнеров

[containers.md](c4/containers.md) — показывает высокоуровневую архитектуру системы: основные подсистемы (фронтенд, бэкенд, база данных) и их взаимодействие.

### Диаграмма компонентов

[components.md](c4/components.md) — показывает внутреннюю структуру контейнеров, разбивая их на логические компоненты и связи между ними.

## ER-диаграмма

[er-diagram.md](db/er-diagram.md) — диаграмма сущностей и связей базы данных. Показывает структуру таблиц и отношения между ними.

Приложение использует следующие таблицы:

- **users** — все пользователи системы
- **student_profiles** — профили учеников
- **tutor_profiles** — профили репетиторов
- **subjects** — справочник предметов
- **tutor_subjects** — связь репетиторов и предметов
- **applications** — заявки от учеников к репетиторам

## Работа с диаграммами

Диаграммы созданы с использованием библиотеки [Mermaid](https://mermaid.js.org/).

Для просмотра диаграмм в VS Code установите расширения:

- **Markdown Preview Mermaid Support** — предпросмотр диаграмм в Markdown
- **Code Spell Checker** — проверка орфографии
- **Russian - Code Spell Checker** — проверка орфографии на русском языке

Также можно использовать [онлайн-редактор Mermaid](https://mermaid.live/edit) для просмотра и редактирования диаграмм.
