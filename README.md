# tutor-finder-docs
Документация web-приложения для онлайн-подбора репетиторов

Tutor Findee — web-приложение для онлайн-подбора репетиторов, ориентированное на школьников и студентов, с функциями специально адаптированными под учебный процесс: подбор репетиторов, фильтрация по предметам, отправка заявок, управление заявками.
